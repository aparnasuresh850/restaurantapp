RESTAURANT SELF-ORDERING SYSTEM - JAVA SWING

Files: Food.java, CartItem.java, RestaurantApp.java

Run:
1. Put all three Java files in the same folder.
2. Open a terminal in that folder.
3. Compile: javac Food.java CartItem.java RestaurantApp.java
4. Run: java RestaurantApp

PowerShell with the JDK 8 path used earlier:
& "C:\Program Files\Java\jdk1.8.0_202\bin\javac.exe" Food.java CartItem.java RestaurantApp.java
& "C:\Program Files\Java\jdk1.8.0_202\bin\java.exe" RestaurantApp

Admin demo password: admin123

Includes role selection, customer name/table, food selection, cart, quantity editing,
removing/clearing items, automatic total, order summary/bill, and admin add/update/delete
menu management.

Data is stored in memory and resets when the program closes. The hardcoded admin password
is for demonstration only. No database or real payment system is included.

Compile and test in your own environment before submitting.
